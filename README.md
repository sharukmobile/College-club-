College Club Management System

📌 Project Overview

The College Club Management System is a web-based application designed to manage college clubs, student memberships, events, and extracurricular activities. It provides a centralized platform for students, faculty coordinators, and administrators to organize and manage club activities efficiently.

🎯 Objectives

- Simplify college club management.
- Allow students to explore and join clubs.
- Organize and manage college events.
- Track student participation and attendance.
- Reduce manual paperwork.
- Improve communication between students and coordinators.

🚀 Features

- Student Registration and Login
- Admin Dashboard
- Create and Manage Clubs
- Join and Leave Clubs
- Student Member Management
- Event Creation and Scheduling
- Online Event Registration
- Attendance Tracking
- Notifications and Announcements
- Participation History
- Reports and Statistics
- Responsive User Interface

🛠️ Technologies Used

- HTML5 – Website Structure
- CSS3 – Styling and Responsive Design
- JavaScript – Interactive Functionality
- LocalStorage – Browser-based Data Storage
